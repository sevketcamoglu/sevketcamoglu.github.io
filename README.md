# Academic website — source files

This repository builds Sevket Camoglu's personal academic website using
Jekyll, hosted for free on GitHub Pages.

- Site settings (name, email, social links): edit `_config.yml`
- Home / CV / Teaching / About / Contact: edit the `.md` files in the root
- Add a working paper: add a file to `_working_papers/`
- Add a publication: add a file to `_publications/`
- Add work in progress: add a file to `_wip/`
- Add a conference talk: add a file to `_presentations/`
- CV and paper PDFs: `assets/pdf/cv/` and `assets/pdf/papers/`
- Profile photo: `assets/images/profile.jpg`

See the full setup and maintenance guide provided alongside this template
for click-by-click instructions.
